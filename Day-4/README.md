# Day 4 – Your First Lightning Web Component (LWC)

## Objective

The objective of Day 4 was to understand Lightning Web Components and build the first user interface for the Placement Management System.

## Work Completed

- Created the first Lightning Web Component.
- Learned the structure of an LWC.
- Worked with HTML, JavaScript, and Meta XML files.
- Implemented basic data binding.
- Created buttons and handled click events using JavaScript.
- Built a basic Airport Gorund Operations Management interface.
- Deployed the LWC to a Lightning Page.
- Practiced building UI without Apex or database connectivity.

## Learning Outcome

Learned how LWC is used to build reusable Salesforce user interfaces and understood the role of HTML, JavaScript, and Meta XML files in an LWC.

## Conclusion

Day 4 provided hands-on experience with building the first Lightning Web Component and understanding how the Salesforce UI layer works.
